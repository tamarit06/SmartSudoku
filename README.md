# SmartSudoku

SmartSudoku is a Sudoku application developed in Haskell.

The project aims to implement an intelligent Sudoku solver and generator, with a focus on functional programming, algorithm optimization and problem solving.

## Planned features

- Sudoku board representation and validation.
- Sudoku solver using backtracking.
- Automatic Sudoku generation.
- Unique-solution validation.
- Difficulty levels.
- Graphical user interface.
- Scoring system.

## Technologies

- Haskell
- GHC
- Cabal
- Gloss (planned for the graphical interface)

## Project status

Currently in the initial development phase.
